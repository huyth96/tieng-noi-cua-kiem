# Tiếng Nói Của Kiếm — Act 1 (bản chơi thử trên web)

**Chơi ngay:** https://huyth96.github.io/tieng-noi-cua-kiem/

Nên chơi trên máy tính (Chrome / Edge / Firefox), có bàn phím. Lần đầu mở trang cần chờ tải khoảng 60 MB.
Bấm vào khung game một lần để game nhận phím và bật âm thanh.

## Điều khiển

| Phím | Hành động |
|---|---|
| WASD / phím mũi tên | Di chuyển |
| Shift | Chạy |
| E / Space / Enter | Tương tác, qua thoại |
| Tab (giữ) | Tua nhanh thoại |
| J / chuột trái | Chém (đúng lúc vòng sáng khép lại = Chuẩn nhịp) |
| K / chuột phải | Trầm kiếm (giữ để đỡ; nhấn ngay trước khi trúng đòn = Hóa giải) |
| L / Q | Đoạt kiếm (khi Silas sơ hở và Focus đầy) |
| Esc | Tạm dừng |
| F11 | Toàn màn hình |

Repo này chỉ chứa bản build web đã đóng gói của game (xuất bằng Godot 4.7).
